06 / 核心原型：数据库管理OBJECT → VIEW → ACTION

数据库、表、记录：三个层级不再混在一起

对象导航独立

左侧应用导航负责功能；第二列仅列出当前数据库对象，避免两套同权菜单。

宽表只在表内滚动

RID、BIGINT、长字段和操作列保持可辨；整个应用不横向溢出。

空值语义明确

NULL、空字符串、长内容截断分别展示，不用同一种空白混淆。

危险操作说明对象与影响

删除确认显示 school.db / student / RID 3/0 以及自动提交状态。

结构 / 索引页签保持当前表对象不变07 / 11
