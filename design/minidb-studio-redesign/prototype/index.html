帮助与说明

快速找到限制、术语和下一步

固定入口，不要求用户记住导航路径。

5 分钟上手

  1. 1创建或打开数据库
  2. 2在数据库管理中选择表
  3. 3执行 SQL 并查看计划

关键限制

  • DDL 不支持事务回滚。
  • BIGINT 以字符串传输。
  • 实验库和工作库严格隔离。

错误处理

  • RID 过期：刷新后重试。
  • 会话过期：未提交事务已回滚。
  • 服务断开：保留 SQL 草稿。
